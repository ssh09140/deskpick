# UI 점검 — 2026-10-31

## 점검 범위

로컬 개발 서버에서 인앱 브라우저의 화면 너비를 조절해 점검했다. 실제 휴대폰 기기 테스트는 아니다.

- 너비: 320, 390, 744, 768, 1024, 1440px
- 경로: `/`, `/products`, `/products/ikea-80474783`, `/studio`, `/guide`, `/login`, `/signup`, `/forgot-password`, `/account`, `/terms`, `/privacy`, `/auth/callback`, `/not-found`
- 13개 경로 × 6개 너비 = 78개 조합의 가로 넘침 및 주요 조작 요소 크기 검사
- 주요 화면은 스크린샷으로 여백, 줄바꿈, 정렬을 별도 확인

## 수정 내용

- 필터·정렬 선택 상자의 화살표를 안쪽으로 배치하고 텍스트 공간 확보
- 시뮬레이터 선택 제품 카드 내부 여백 및 동작 버튼 정렬 통일
- 제품 카드의 긴 이름 줄바꿈, 가격 위치, 보조 글자 대비 개선
- 모바일 카테고리 이름, 섹션 링크, 좁은 화면의 필터·상세 사양 배치 개선
- 모바일 약관·개인정보 페이지의 본문 안쪽 여백 복원
- 비밀번호 표시·팝업 닫기 등 주요 아이콘 버튼을 44px 크기로 확장
- 팝업 제목과 닫기 버튼 공간 분리, 제품 추가 팝업의 중첩 스크롤 제거
- FAQ 펼침 표시와 클릭 영역 개선, 푸터 링크 간격 및 짧은 페이지의 푸터 위치 정리
- 모바일 전환 기준을 767/768px로 통일

## 검증 결과

- 78개 화면 조합에서 문서 가로 넘침 없음
- 검사 대상 버튼·선택 상자·작은 섹션 링크에서 32px 미만의 조작 영역 없음(책상 위 배치 도형 제외)
- 제품 추가 팝업 열기·닫기, 초기화 확인창 취소, 비로그인 저장 시 로그인 팝업 확인
- 로그인/회원가입 팝업 전환, Escape 닫기, 닫은 뒤 실행 버튼으로 초점 복귀 확인
- 모바일 메뉴 이동 후 닫힘, FAQ 펼침 확인
- 빈 카테고리·검색 결과 안내 확인, 필터 초기화 후 기존 제품 15개 복원 확인
- `npm run build` 통과
- `npm test`: 6개 파일, 36개 테스트 통과

## 검증 한계 및 증거

로그인하지 않은 상태에서 진행했다. 로그인 후 계정 화면, 실제 저장·탈퇴, 이메일 인증·비밀번호 재설정 완료 흐름은 이번 UI 검증에 포함하지 않았다. 실제 iOS Safari와 Android 기기에서의 터치 동작도 별도 확인이 필요하다.

로컬 스크린샷과 측정 결과는 Git에서 제외된 `design/review/ui-audit/`에 보관했다. `results.json`은 수정 후 화면 크기별 측정 결과이며, `after-products-mobile.png`와 `after-terms-mobile.png`는 수정 후 모바일 화면이다. 기존 너비 접두어 스크린샷은 초기 점검 기록이다.
