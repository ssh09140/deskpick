# 상품 탐색 분류

- 추천 분류: 전체 제품 / 가성비 추천(`value`) / 운영자 추천(`curator`)
- 큰 카테고리: 책상 / 모니터·거치대 / 키보드·마우스 / 오디오·마이크 / 조명 / 충전·연결 / 패드·수납·정리 / 데스크 소품
- 세부 카테고리: `src/lib/catalog.ts`의 `catalogCategories`에서 정의. 실제 등록 상품이 있는 세부 품목만 표시.
- 필터: 가격 상한 / 브랜드 / 색상. 추천·큰 카테고리·세부 카테고리와 AND 조건으로 결합.
- 정렬: 기본순 / 낮은 가격순 / 높은 가격순.

큰 카테고리는 등록 상품이 없어도 표시하며 준비 중 안내를 제공합니다. 추천 상품은 아직 선정하지 않아 두 추천 목록 모두 준비 중으로 표시합니다. 기존 상품에 임의의 추천 배지를 부여하지 않습니다.

## 기존 상품 유지

`products.json`의 상품 ID, 가격, 치수, 사진, 판매처 링크는 변경하지 않았습니다. 기존 숫자형 `cat`은 저장 데이터와 이전 링크 호환을 위해 유지하며 탐색 화면에는 새 분류를 매핑합니다. 기존 숫자 카테고리 URL도 대응하는 큰 카테고리로 연결됩니다.

현재 브랜드는 기존 상품 ID로 IKEA와 Apple을 구분합니다. 색상은 이름에 명시된 화이트·블랙·다크옐로·투명만 반영하며, 명시되지 않은 색상을 사진으로 추정하지 않습니다.

## 추후 상품 등록

새 상품의 분류는 `catalogOverrides[상품ID]`에 `category`, `subcategory`, `brand`, `colors`, `recommendations`를 지정합니다. ID는 `catalogCategories`의 값을 사용합니다. 기존 숫자 분류는 새 상품 분류의 기준으로 사용하지 않습니다.

추천 태그는 `['value']`, `['curator']`, 또는 `['value', 'curator']`로 지정할 수 있습니다. 선정 후 상품의 추천 설명(`why`)도 실제 선정 이유에 맞게 작성합니다.

가격·브랜드·색상과 선택 상태는 URL에 반영되어 새로고침과 뒤로가기로 복원됩니다. 큰 카테고리를 바꾸면 이전 세부 선택은 해제됩니다. 초기화는 검색어·추천·카테고리·필터·정렬을 함께 초기화합니다.

책상 변경, 클램프 설치, 모니터 부착 등의 새로운 배치 동작은 이번 분류 변경에 포함하지 않습니다. 해당 종류의 상품을 실제로 추가할 때 설치 유형과 배치 지원을 함께 검토해야 합니다.
